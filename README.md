# One More In The Chamber

A roguelike match-3 set in a spaghetti western world. Play as a red panda cowboy fighting through three acts of outlaws, snakes, and corrupt sheriffs. Match tiles to shoot, block, and earn gold. Collect artifacts that synergize through trait tags. Choose new tile types between acts -- each one makes you stronger but dilutes your board. One more tile. One more chamber. One more chance.

**Stack:** Phaser 3 + React + TypeScript, hosted on Cloudflare Pages with Supabase backend. Free to play, free to host.
