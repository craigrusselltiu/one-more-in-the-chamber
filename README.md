# One More In The Chamber

**[Play Now](https://craigrusselltiu.github.io/one-more-in-the-chamber/)**

Alpha v1.1.0

A roguelike match-3 set in a spaghetti western world. Fight through three acts of outlaws, snakes, and corrupt sheriffs by matching tiles to shoot, block, heal, poison, and earn gold. Collect artifacts that synergize through trait tags, choose new tile types between acts, and build a board that gets stronger and harder to control with every reward.

One more tile. One more chamber. One more chance.

## Features

- Play as Rust or Reno, each with their own core tile and charged ability.
- Build runs from match-3 combat, map routing, merchants, events, campfires, treasures, elites, and bosses.
- Discover artifacts, consumables, tile upgrades, status effects, and character-specific strategies.
- Unlock meta progression through reputation, cosmetics, ledger discoveries, and leaderboards.
- Continue saved runs locally with IndexedDB persistence and combat snapshots.

## Latest Update

Alpha v1.1.0 adds locked placeholder slots for Rudy, Reap, Rita, and Riff, with pre-run dialogue already in place for each future character. It also refines tutorial placement, tooltip behavior, score screen readability, combat settings styling, and several UI details across character select and combat.

## Controls

- Click and drag adjacent tiles to swap them.
- Match three or more tiles to resolve their effects.
- Use the character ability when the meter is full.
- Route through the map by selecting reachable nodes.

## Tech Stack

Phaser 3 + React + TypeScript, hosted on GitHub Pages with a Supabase backend.
