# Future Ideas

## Difficulty & Board Mechanics

### Board Manipulation (harder)
- **Immovable tiles** - Tiles that can't be swapped but CAN be matched. Forces the player to build matches around them.
- **Board shape** - Instead of a full 8x8, certain bosses or elite modifiers could change the playable area (block off corners, hourglass shape, L-shape, cross). Visually dramatic, changes difficulty without adding tile types.
- **Corruption spread** - Like prairie fire but for the enemy. Matched enemy-type tiles spread a debuff. Player must match them to cleanse but matching them also feeds the enemy.
- **Tile decay** - Tiles that weaken over time if not matched (e.g. a gold tile that loses 1 value per turn, eventually becoming worthless). Creates urgency without adding types.
- **Cursed tiles** - Look like a normal tile but when matched, trigger the enemy's effect instead of yours. Clearing them gives bonus resources but accidentally matching them hurts you. Fool's Gold is a light version of this.

### Board Manipulation (easier)
- **Wild tiles** - A tile that matches with ANY type. Rare spawn, big cascade potential.
- **Tile weighting** - Instead of even distribution, bias the bag toward types the player needs. Could tie this to an artifact or trait.
- **Cascade seeds** - When filling empty cells, slightly bias toward creating near-matches (2-in-a-row) so the board always feels "almost there."

### Pacing & Tempo
- **Tile weighting per encounter** - Certain enemies could flood the board with a specific type (e.g. a poison enemy makes venom tiles spawn 2x as often). Doesn't add types but changes the feel of every fight.
- **Mirrored tiles** - Two tiles on the board are linked. Matching one also triggers the other (could be good or bad depending on what's adjacent).
